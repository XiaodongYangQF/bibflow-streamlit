## Version 2.2B — Compact Advanced Ranking View

BibFlow now uses a cleaner two-level ranking display.

### Main ranking view

The default Research Library table focuses on the most useful ranking indicators:

```text
AJG Rating · AJG Field · FT50 · ABDC Rating · JCR Quartile · SJR Quartile · SSCI
```

### Advanced ranking details

Less frequently used matching and source-checking fields are moved into the advanced section:

```text
AJG Source Year · SSCI Categories · Custom Rating · Ranking Tags · Matched Journal · Match Method · Match Score · Ranking Source · Ranking Match Note
```

Columns such as CSSCI, Chinese Core, School Tier, and ABDC Field are hidden from the current UI because they are not part of the active workflow yet.
