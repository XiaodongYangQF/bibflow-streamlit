## Version 2.2 — Multi-Ranking System Support

BibFlow now supports uploaded multi-ranking files. In addition to AJG/ABS-style ratings and FT50 indicators, the Research Library can detect and filter:

- ABDC-style ratings
- JCR quartiles
- SJR quartiles
- CSSCI-style list membership
- Chinese Core-style list membership
- school-specific tiers
- custom user-defined ratings
- ranking tags

Use `examples/sample_multi_rankings_demo.csv` to test the workflow.

> Ranking systems classify journals or list membership, not individual paper quality. Use these fields as context for literature-review planning and publication-strategy awareness.
