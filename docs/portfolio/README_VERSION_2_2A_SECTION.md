## Version 2.2A — Compact Ranking View

BibFlow now uses a cleaner default ranking view for research-library work. The main table focuses on the most useful international academic indicators:

```text
AJG Rating · AJG Field · FT50 · ABDC Rating · JCR Quartile · SJR Quartile · SSCI
```

Additional columns such as ABDC Field, CSSCI, Chinese Core, school-specific tiers, custom ratings, ranking tags, and matching diagnostics remain available under **Advanced ranking and matching details**.
