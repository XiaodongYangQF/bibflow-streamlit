# BibFlow Version 2.1C — Deployment Polish

## Purpose

Version 2.1C prepares BibFlow for public deployment and portfolio use.

This version focuses on repository hygiene, Streamlit deployment configuration, and safe handling of private journal ranking data.

## Added

- `requirements.txt`
- `.streamlit/config.toml`
- `.gitignore` additions for private ranking files and local exports
- `DEPLOYMENT_GUIDE_v2_1C.md`
- `README_DEPLOYMENT_SECTION_v2_1C.md`

## Deployment improvements

- Clear Streamlit theme configuration
- Explicit package requirements
- Public-demo workflow guidance
- Private data protection guidance
- Deployment checklist
- Suggested Git tag for release

## Important note

BibFlow should not redistribute the official AJG/ABS ranking dataset unless redistribution is clearly allowed.

The public demo ranking file should remain a small example file for testing only.
