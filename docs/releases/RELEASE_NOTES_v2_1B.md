# BibFlow Version 2.1B — Sample Files and Demo Data

## Added

- Public demo BibTeX file
- Public demo journal ranking CSV
- Public demo annotated research library CSV
- Usage guide for testing the Research Library workflow

## Purpose

Version 2.1B makes BibFlow easier to demonstrate on GitHub, Streamlit Community Cloud, and a personal portfolio website.

The sample data supports testing:

- BibTeX parsing
- AJG/ABS-style matching
- FT50 filtering
- unmatched journal warnings
- reading status and notes
- annotation restore
- dashboard/report export

## Notes

The demo ranking file is not the official AJG/ABS dataset.
It is a small example file for testing BibFlow's matching workflow.
