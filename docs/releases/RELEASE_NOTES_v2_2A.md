# BibFlow Version 2.2A — Compact Ranking View

## Purpose

Version 2.2A simplifies the Research Library ranking display while keeping advanced ranking columns available for checking and future extensions.

## Main ranking metrics shown by default

- AJG Rating
- AJG Field
- FT50
- ABDC Rating
- JCR Quartile
- SJR Quartile
- SSCI

## Moved to advanced view

- AJG Source Year
- ABDC Field
- SSCI Categories
- CSSCI
- Chinese Core
- School Tier
- Custom Rating
- Ranking Tags
- Matched Journal
- Match Method
- Match Score
- Ranking Source
- Ranking Match Note

## Notes

This version keeps all data in the full CSV export, but the default app table is now cleaner and easier to read.
