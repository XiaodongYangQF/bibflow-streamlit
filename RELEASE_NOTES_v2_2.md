# BibFlow Version 2.2 — Multi-Ranking System Support

## Purpose

Version 2.2 extends BibFlow from AJG/ABS + FT50 matching to a more general multi-ranking research library workflow.

## Added

- ABDC-style rating support
- JCR quartile support
- SJR quartile support
- CSSCI-style list indicator support
- Chinese Core-style list indicator support
- School-tier and custom-rating support
- Ranking tags support
- Multi-ranking filters in the Research Library tab
- Multi-ranking summary metrics
- Multi-ranking distributions in the dashboard
- Multi-ranking fields in the annotated CSV export
- Multi-ranking fields in the literature-review Markdown report
- Public demo multi-ranking CSV template

## Notes

The app does not redistribute official ranking datasets. Users should upload their own ranking files when allowed.

The demo ranking file is intentionally small and synthetic, designed only for testing the BibFlow matching workflow.
