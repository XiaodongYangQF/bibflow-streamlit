# BibFlow Version 2.1E — Portfolio Copy

## One-line description

BibFlow is a Streamlit research workflow app for cleaning BibTeX references, managing literature libraries, matching AJG/ABS-style journal rankings, and tracking literature-review progress.

## Short portfolio description

BibFlow is a research productivity tool designed for PhD students and academic researchers who work with Zotero, BibTeX, Overleaf, and journal ranking systems. It supports DOI-based BibTeX generation, batch reference processing, BibTeX cleaning, quality checks, research-library exploration, AJG/ABS-style journal ranking matching, FT50 indicators, reading-status tracking, notes, tags, and literature-review report export.
